## Ticket 32 — completion reader/writer strategy

- **Status:** type=grilling, status=claimed, blocked by=none. No research/design output yet. `docs/raw/ls-backlog/issues/32-rearchitect-completion-reader-writer-strategy.md`
- **Current design (index/lease/degrade):** precomputed, generation-scoped indexes stored with stable snapshots; non-blocking exact-generation lease; syntax-only fallback when matching generation unpublished. `docs/raw/decisions/2026-07-16-completion-vertical-slice.md:Decision`, `docs/raw/decisions/2026-07-16-expected-type-completion-projections.md:Decision`
- **Question 1 (ST removal):** should cursor-context classification stop depending on red-facade `tree.*` layer entirely (per ls-ref PoC pattern via `NewRecoveringNodeBuilder`), or does red facade earn its keep for syntactic classification specifically? `docs/raw/ls-backlog/issues/32-rearchitect-completion-reader-writer-strategy.md:Question §1`
- **Question 2 (reader/writer strategy):** can/should compile move from index-plus-lease-plus-degrade toward rust-analyzer's on-demand incremental query + cancel-the-reader-on-write model, and if compiler's monolithic walk-and-bind pass makes full Salsa-style incrementality infeasible without compiler rewrite, what smaller-scope adoption is viable (e.g. cooperative compile cancellation shrinking lease-miss window)? `docs/raw/ls-backlog/issues/32-rearchitect-completion-reader-writer-strategy.md:Question §2`
- **No prior Salsa-style incrementality comparison:** ticket 32 is the first design doc to explicitly raise rust-analyzer's model; prior docs avoid it (focused on avoiding ls-ref's sync-per-request pattern instead). Compiler constraint: `PackageCompilation` is synchronous `sync.Once` with no mid-compile hooks; ADR-018 §2 downgrades phase-boundary checkpoints to "future enhancement pending API exposure." `docs/raw/decisions/2026-07-14-dual-snapshot-compiler-engine.md:39-44`
- **No design decision on compile-generation granularity:** whole-package/whole-module is implicit in ADR-049 (resolution-first per package), ADR-058 (dual snapshots per source root), and compiler architecture (`PackageCompilation` walks modules). No doc compares per-file or per-function granularities; finer-grained memoization deferred by monolithic compiler structure.
- **Lease-miss window term originates in ticket 32:** current design documented in completion vertical-slice (precomputed index, full-compile boundary, exact-generation lease). Debounce tunable 150ms default in ADR-058 branch 7 (2026-07-14-dual-snapshot-compiler-engine.md:396,407) but no separate shrink-window design; cooperative compile cancellation not separately designed (would require compiler API changes per ADR-018 §2).
