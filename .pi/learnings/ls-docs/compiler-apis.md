# Compiler APIs

- **BallerinaCompilerApi for loading/discovery only:** ADR-061 narrows ADR-045 — project loading, workspace discovery, compiler environment entry points go through BallerinaCompilerApi. Owned-object navigation (Project, Package, Module, Document, PackageCompilation, SemanticModel, SyntaxTree) may be direct inside WM and CE. `architecture/adrs/ADR-061-compiler-sdk-access-boundary.md`
- **No direct compiler SDK calls outside WM/CE:** ADR-061 — LSP Gateway must not perform compiler orchestration; receives results through service methods and compatibility facade. `architecture/adrs/ADR-061-compiler-sdk-access-boundary.md:Consequences`
- **No BuildOptions.setSticky(true):** ADR-061 — new code must use explicit LockingMode semantics. `architecture/adrs/ADR-061-compiler-sdk-access-boundary.md:Decision`
- **Resolution-first pipeline:** ADR-049 — CE calls pkg.getResolution() first. If resolution fails with qualifying errors → recovery ladder. If non-qualifying → CE-E4 (no compilation). If clean → pkg.getCompilation() + pkg.getBuildToolResolution() → CE-E5. `architecture/adrs/ADR-049-resolution-first-pipeline-recovery-ladder.md`
- **CE-E5a/CE-E5b mutual exclusivity:** ADR-060 — resolution diagnostics and compilation diagnostics are mutually exclusive per compilation cycle. `architecture/adrs/ADR-060-compilation-event-taxonomy.md`
- **DualSnapshotStore central bounded store:** ADR-058 — 16 stable snapshots default, LRU eviction, eviction listener for WM cleanup. Lock-free stable reads. `architecture/adrs/ADR-058-central-dual-snapshot-store.md`
- **Compiler API immutability guarantee:** ADR-042 §Context — document.modify().withContent().apply() creates new Document/Module/Package objects; old objects unchanged. Structural sharing free. `architecture/adrs/ADR-042-dual-snapshot-access-pattern.md:Context`
- **Cancellation via thread interrupt:** ADR-018 — no compiler API cooperative cancellation hooks available yet. Thread interrupt is safe because compiler is side-effect-free. Phase-boundary checkpoints are future work. `architecture/adrs/ADR-018-cooperative-cancellation-model.md:Mandate 8`
- **CompilationService API:** api-contracts.md — exposes stableSnapshot(Project, PackageDescriptor, CancelChecker) and latestSnapshot(Project, PackageDescriptor, CancelChecker). No Path-based syntax-tree/semantic-model methods. `architecture/structural/api-contracts.md:CompilationService`
